# پنل مدیریت Atomic School

## چه کاری انجام می‌دهد؟
- ورود با Firebase Authentication
- ثبت عنوان، توضیح و کد/متن در مجموعه `sitePosts` در Firestore
- نمایش فهرست مطالب ذخیره‌شده برای مدیران

## مهم
این فایل هنوز آمادهٔ انتشار نهایی نیست تا تنظیمات Firebase و ایمیل‌های واقعی هر سه مدیر وارد شوند. فقط ایمیلی که در کد قوانین مجاز است و با حساب تأییدشده وارد شود، می‌تواند به مجموعه `sitePosts` دسترسی داشته باشد. ایمیل تایپ‌شده در یک فرم به‌تنهایی اثبات هویت نیست.

## راه‌اندازی
1. در Firebase Console پروژه‌ای بسازید.
2. در Authentication، روش Email/Password را فعال کنید.
3. برای هر سه مدیر حساب بسازید و ایمیل‌ها را تأیید کنید.
4. Firestore Database بسازید.
5. در فایل `firestore.rules` مقدارهای `FRIEND_EMAIL_HERE` و `TEACHER_EMAIL_HERE` را با ایمیل‌های واقعی جایگزین کنید؛ ایمیل‌ها باید در کوتیشن باشند.
6. قوانین را در Firebase Console > Firestore Database > Rules منتشر کنید.
7. از Project settings > Your apps، تنظیمات Firebase Web App را کپی و در `admin.html` داخل `firebaseConfig` جایگزین کنید.
8. `admin.html` را به ریشه مخزن GitHub Pages اضافه کنید؛ بعد از انتشار، مسیر آن معمولاً `/atomic-school-coding/admin.html` خواهد بود.

## محدودیت فعلی
این پنل محتوا را در Firestore ذخیره می‌کند؛ خودش فایل‌های HTML سایت یا مخزن GitHub را تغییر نمی‌دهد و به‌طور خودکار محتوای جدید را در صفحه اصلی نشان نمی‌دهد. برای نمایش خودکار مطالب، باید `index.html` هم به Firestore متصل شود. برای تغییر مستقیم فایل‌های GitHub باید یک بک‌اند امن یا GitHub App/Actions با دسترسی محدود طراحی شود؛ توکن خصوصی GitHub را هرگز در HTML قرار ندهید.

## نکتهٔ امنیتی
قوانین Firestore مرجع اصلی مجوز هستند؛ صرفاً مخفی کردن دکمه‌ها یا بررسی ایمیل در JavaScript امنیت ایجاد نمی‌کند. قوانین فعلی اجازه خواندن و ایجاد محتوا را به مدیران می‌دهند و ویرایش/حذف را مسدود می‌کنند.
